# Marine Image Study

This study investigates how well people recall image details for a specific dataset (Marine Video Kit).

Initially, you will be shown an image like the one below for 10 seconds.

<img src="/assets/fish.jpg" alt="image" width="300"/>

You will be then asked to solve a simple, unrelated math problem.
In case you struggle with it, the problem will automatically go away after 15 seconds.

Next, you will be presented with a blank canvas and two text input boxes.
The first one is for the global description of the image you were shown.
Try to recall as many details as you can.

The second one is for a specific part of the image you found interesting.
Try to draw the approximate position of the location by holding your left mouse button down.
Then, describe the part of the image in the second text input box.
